# operations-log-helper
기업 시스템 운영자를 위한 대용량 로그 검색·분석 도구 - AI 계정 연동과 원격 서버(SFTP) 연결을 지원하여 로그 수집부터 검색·분석까지 통합 제공

**운영 로그 도우미 (Operations Log Helper)**

기업 시스템 운영 담당자를 위한 대용량 로그 검색 도구입니다.

주요 기능
- 대용량 로그 파일 검색
- 기준 날짜 및 시각 전후 로그 확인
- RFC 요청·응답 및 오류 검색
- 매장코드, 제품코드 등 다중 조건 검색
- SFTP 서버 연결 및 로그 파일 수집
- AI 계정 연동 및 AI분석
  
사용 대상
POS / ERP / 레거시 시스템 운영 담당자, 유지보수 개발자
다운로드
Releases에서 최신 버전 ZIP을 내려받을 수 있습니다.
제작 배경
기업 시스템 운영 과정에서 반복되는 로그 분석 업무를 간소화하기 위해 제작했습니다.
